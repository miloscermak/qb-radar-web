# QB Radar – přesměrování

Aplikace běží na **https://qb-radar.netlify.app/**. Redakce se přihlašuje heslem, GitHub účet ani token nepotřebuje.

Tento veřejný repozitář zachovává původní GitHub Pages adresu a přesměrovává ji na aktuální aplikaci. Soukromé texty článků, konfigurace zdrojů a přístupové klíče zde nejsou.
