# QB Radar – přesměrování

Aplikace běží na **https://qb-radar.netlify.app/**. Redakce se přihlašuje heslem, GitHub účet ani token nepotřebuje.

Tento veřejný repozitář zachovává původní GitHub Pages adresu a přesměrovává ji na aktuální aplikaci. Soukromé texty článků, konfigurace zdrojů a přístupové klíče zde nejsou.

## Předání projektu

[Podrobný předávací protokol pro nového správce a jeho Codex](PREDANI-CODEX.md) popisuje architekturu, přístupy, provoz, nasazování a další postup. Obsahuje také úvodní zadání pro nový Codex.

Kód aplikace a neveřejná data jsou v samostatném soukromém repozitáři `miloscermak/qb-radar-pilot`. Cesty v protokolu se vztahují k tomuto repozitáři; zde je veřejná kopie dokumentu bez hesel a tokenů.
